## Correctness and minimality

The helper recognizes whole marker tokens from the current generated population, then requires their expected specialist publisher for Fact-backed results. Unknown tokens and substring prefixes cannot earn credit. A Fact carrying another target's marker cannot earn that target's identity. Text-only results use known marker identities without claiming verified publisher provenance. In the Fact path a missing publisher also earns no credit; it does not silently fall back to text-only trust.

Both conceptual and marker-named measurements now share that interpretation. Exact recall/diversity are computed from the unique target-identity intersection; equivalent-domain coverage comes only from recognized shard identities, not generic/near-miss authorship. Repeated rows cannot multiply one target into three, push fractions above one, or make the deepest first-hit rank worse. A later new target correctly advances that rank. Empty output yields zero recall and the existing no-target rank sentinel. The regression cases exercise the formerly false binding PASS, equivalent peers, borrowed markers, prefix collisions, duplicates and correct sources.

`distractor_rate` remains a per-returned-row exact-target measure. Duplicate exact-target rows are still target rows, and useful non-target same-domain peers are still counted as distractors. It is neither duplicate-waste rate nor a semantic usefulness metric. `agent_diversity` retains its existing exact-target-normalized meaning. The rank is the deepest first occurrence among targets actually found; partial coverage can have a low rank, so rank must be read with recall.

## What the corrected score establishes

This is a source-identity proxy for a controlled generated corpus. A copied, quoted or marker-only text can still satisfy the helper without containing the substantive implementation statement; publisher strings are not authenticity proofs. The helper's docstring and plan explicitly exclude entailment. Do not describe the correction as validating arbitrary real-world evidence content, causal sufficiency, answer quality or successful agent decisions.

The conceptual query contains the domain's query-concept text, which also appears verbatim in each shard; this fixture does not isolate semantic paraphrase retrieval. Exact specialist identity remains underdetermined among equivalent same-domain peers. Neither observed 1/3 exact recall nor a particular returned length establishes a universal ceiling/floor. The default N=10/100/1000 probes use distinct target domains. The pre-existing arbitrary-scale generator can choose repeated domains (for example N=60); equivalence still divides by three, so this review does not establish correctness of every configurable duration checkpoint.

The S9/S19 advisory analyses accurately distinguish source availability from suppression/precision. S9's legacy `supersession_propagation` keyword presence is not proof of a CAS transition when the initial slotted version was never inserted. S19's score is keyword-positive returned-row precision with variable result length. These limitations do not justify a new provider dependency or a retrieval change in this patch.
