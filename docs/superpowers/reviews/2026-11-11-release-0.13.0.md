# Release 0.13.0 review

The release combines the accepted always-on team memory changes with the deferred
0.13.0 version preparation. The original checkout, including its untracked
research, remains byte-for-byte unchanged. Only its tracked release patch was
applied to this branch; current task/experience documentation was retained.

The owner applied the Ponytail quality-review checklist to the release diff and
connected version loaders, release renderer, npm packaging, upgrade behavior and
transport examples. No new dependency, service, abstraction or model default is
introduced. Python, npm, lockfile root and MCP package versions all match 0.13.0.
The existing release workflow now also bumps the MCP manifest. Release-specific
assertions use the package version instead of the old 0.12.0 literal. No actionable
release-diff finding remains; this is an owner review, not an additional independent
review or Astra run. The feature and replay corrections have their own independent
review in [the source-context review](2026-11-11-source-context-independent.md).

All 18 local source gates passed after the full release batch: Python 3.11/3.12/3.13,
required PostgreSQL on 3.12, MCP subprocesses, both recovery backends, 8-process load,
TypeScript tests/typecheck/build/package audit, and release preflight. Exact counts,
commands, results and bounded-load measurements are retained in
[validation](../validation/2026-11-11-release-0.13.0.json). Local artifact installation
and public-registry installation are separate acceptance steps. These gates do not
prove published package availability or general model accuracy.
